# DEEN QUEST — FINAL GitHub Pages Package

This version is intentionally **single-file** so GitHub Pages cannot break because CSS/JS/logo/image files are in the wrong folder.

## Upload
1. Open the ZIP.
2. Upload **index.html** and **.nojekyll** directly into the repository root.
3. Do NOT put them inside another folder.
4. GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
5. Wait for deployment, then hard-refresh the site with `Ctrl + F5`.

Everything needed for the app (CSS, JavaScript, 50-level question data, logo and background) is embedded in `index.html`.
